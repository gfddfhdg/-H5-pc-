# 知识付费系统源码 支持H5、小程序和pc端分站分销多种变现模式

源码获取：ym7k.com/19803/

这套知识付费源码采用 ThinkPHP+Uniapp 主流架构，一套源码同步支持**PC 管理端、H5、微信小程序**三端访问，集成分站独立运营、多级分销、多样化内容变现能力，适合知识博主、培训机构、网校、自媒体团队搭建私有化知识付费平台，源码可二次开发，私有化部署。

## 一、技术架构

后端基于 ThinkPHP（常搭配 FastAdmin），Uniapp 开发移动端，可打包 H5、微信小程序；PC 前台独立展示页面，搭配完整后台 RBAC 权限体系，文件上传、支付、短信、海报生成、数据统计等基础组件齐全，部署简单，改 LOGO、配置域名即可快速上线。

## 二、核心内容模块（知识付费载体）

1. **图文专栏**：系列图文课程、干货文档、付费专栏，支持单篇购买、整套订阅
2. **视频课程**：录播视频课，支持视频加密防下载、试看时长设置、倍速播放、课程目录管理
3. **音频课程**：音频专辑、电台、有声课程，适合碎片化收听，支持后台上传音频素材
4. **付费文档 / 资料**：PDF、Word、模板资料售卖，购买后在线预览或下载
5. **直播课程（可选拓展）**：视频直播、直播回放、直播预约、直播带货
6. **题库答题（可选拓展）**：配套刷题、线上考试，课程 + 题库组合售卖
7. **社群 / 问答**：付费问答、付费社群入群，用户付费提问，讲师接单回复

## 三、多种变现模式（重点）

- **单品付费**：单节视频、单篇图文、单个资料单独定价购买
- **专栏 / 专辑订阅**：整套专栏打包优惠购买
- **会员套餐**：月卡 / 季卡 / 年卡会员，开通后全站大部分内容免费看，设置会员专属权益
- **付费社群**：入群费模式，购买后解锁社群入口
- **付费问答**：用户定向付费向老师提问
- **广告变现**：后台开启广告位，banner 广告、信息流广告

## 四、分站功能（核心亮点）

支持分站模式，总后台添加分站，每个分站拥有独立域名、独立 PC+H5 页面、独立 LOGO、独立名称；分站可以单独上架课程、独立收款或者统一平台收款、设置分站分佣比例；分站管理员拥有独立后台权限，只管理自己站点内容、订单、学员，适合招商加盟、渠道代理、多区域分校运营。

## 五、分销推广体系

- 支持分销推广，生成专属推广海报、推广链接
- 自定义分销层级（二级分销为主，合规安全），设置课程、会员的分销佣金比例
- 下级用户下单，上级自动获得佣金，佣金后台可提现
- 分销数据统计：推广人数、订单明细、佣金明细、提现记录
- 支持设置指定课程是否参与分销，灵活控制推广商品

## 六、用户端能力（小程序 / H5/PC 前台）

微信一键登录、手机号绑定；个人中心，我的订单、我的课程、我的收藏、观看历史；分销中心、我的佣金、提现申请；学习进度自动保存；优惠券、限时折扣、拼团、秒杀营销活动；消息通知，订单通知、课程更新通知、佣金到账通知。

## 七、后台管理功能

- 内容管理：课程、专栏、音频、文档、分类、标签、轮播图、公告
- 用户管理：学员列表、用户分组、黑名单
- 订单财务：订单明细、支付记录、退款管理、提现审核、资金流水
- 分销管理：分销设置、佣金比例、推广记录、分销海报配置
- 分站管理：分站新增、分站配置、分站数据查看、分站权限
- 营销工具：优惠券、限时活动、拼团、积分
- 数据统计看板：营收数据、课程销量、新增用户、分销数据图表，支持导出报表
- 系统配置：支付接口（微信支付）、短信、存储、版权信息、权限角色

## 八、适用人群

知识博主、职业培训机构、线上网校、自媒体、技能教学团队、想搭建多分站渠道招商的知识付费服务商。

## 九、系统优势

✅ 三端合一：PC+H5 + 微信小程序，一套代码统一后台管理
✅ 多变现玩法：课程、会员、资料、付费问答全覆盖
✅ 分站招商：支持渠道分站，拓展代理商
✅ 分销裂变：自带分销体系，依靠用户自发推广引流
✅ 源码开放：支持二次开发，可按需新增直播、题库、商城等功能
✅ 数据独立：私有化部署，学员、课程、资金数据自主掌控
